# Assignment4TuteDude
Reading, Writing, Appending and exception Handling in text file

1. File Reader Program (read_file.py)
Description
A Python program that reads a text file named sample.txt and prints its contents line by line with proper error handling.

Features
Opens and reads sample.txt

Prints contents line by line

Gracefully handles file-not-found errors

Catches and reports other unexpected errors


2. File Writer Program (file_operations.py)
Description
A Python program that demonstrates writing and appending to files, then displaying the final content.

Features
Takes user input and writes to output.txt

Appends additional user input to the same file

Reads and displays the final content

Provides success confirmation messages
